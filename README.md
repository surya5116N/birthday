# Sameeha Birthday Website — GitHub Pages

Static GitHub Pages version. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to your repository root.

## GitHub Pages
1. Create/open a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch** → `main` → `/ (root)` → Save.
5. Open the generated Pages URL.
